# Projet : payment-api
Payment Management API

Une API bancaire de gestion des paiements, avec validation, persistance, sécurité, documentation et tests.

Backend
- Spring Boot 4

Langage
- Java 25

Base de données
- PostgreSQL

Build
- Maven

Documentation
- OpenAPI / Swagger

Tests
- JUnit / Mockito

## Ce que tu vas apprendre
Voici le programme complet, organisé dans un ordre pédagogique.
|Étape	|Concepts maîtrisés|
|-------|------------------|
|1	|REST, HTTP, ressources, URI, stateless|
|2	|Spring Initializr et structure Maven|
|3	|Controllers, Services, Repositories|
|4	|GET, POST, PUT, PATCH, DELETE|
|5	|DTO, Records, mapping et JSON|
|6	|Validation et gestion des erreurs|
|7	|HTTP Status Codes et ResponseEntity|
|8	|Pagination, tri et filtrage|
|9	|JPA, Hibernate et PostgreSQL|
|10	|Transactions et verrouillage optimiste|
|11	|Recherche multicritère|
|12	|OpenAPI et Swagger|
|13	|Sécurité Spring Security et JWT|
|14	|Tests unitaires et tests d'intégration|
|15	|Idempotence et gestion des doublons|
|16	|Versionnement et bonnes pratiques REST|
|17	|Docker, Actuator et préparation production|
